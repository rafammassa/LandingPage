# 🚀 RM Soluções Digitais

Landing page desenvolvida com foco em conversão, organização de serviços e apresentação profissional.

## 🌐 Sobre o projeto

Este projeto é uma landing page criada para apresentar serviços de:

- Criação de landing pages
- Automações de planilhas
- Dashboards personalizados

O objetivo é transformar visitantes em clientes de forma simples, direta e estratégica.

---

## ✨ Funcionalidades

- Layout moderno e responsivo
- Seção de apresentação clara e objetiva
- CTA direcionando para WhatsApp
- Estrutura otimizada para conversão
- Organização visual estilo SaaS

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Font Awesome
